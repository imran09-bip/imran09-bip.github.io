নামায সহায়ক — আপডেট নির্দেশিকা

ZIP-এর namaz-sohayok-pages ফোল্ডারের ভেতরের সব ফাইল আপনার Cloudflare Pages বা GitHub repository-র root-এ আপলোড করুন।

এই সংস্করণে:
- বাংলা AI ভয়েসের জন্য /api/speech Cloudflare Pages Function ব্যবহার করা হয়েছে। এতে ব্রাউজারের cross-origin/CORS সমস্যা এড়ানো যায়।
- AI ভয়েস তৈরি না হলে Android/Chrome-এর বিল্ট-ইন বাংলা Text-to-Speech fallback হিসেবে চলবে।
- তৈরি হওয়া ভয়েস একই ডিভাইসে IndexedDB-তে ক্যাশ হয়।
- সূরা আল-ফাতিহা প্রথমে, এরপর আন-নাস থেকে আত-তিন পর্যন্ত ২০টি সূরা আলাদা করে সাজানো হয়েছে।
- নির্বাচিত বড় সূরা আলাদা “ফজিলতপূর্ণ ও নির্বাচিত বড় সূরা” বিভাগে রাখা হয়েছে।
- প্রতিটি অনলাইন সূরায় আরবি তিলাওয়াত ও বাংলা অর্থ শোনার পৃথক বাটন আছে।

নিজস্ব কণ্ঠে AI ভয়েস চালাতে:
1. Cloudflare Pages-এ প্রজেক্ট deploy করুন (GitHub Pages একা Functions চালাতে পারে না)।
2. functions/api/speech.js এবং voice/porosh-reference.wav ফাইল দুটো একই deploy-এ রাখুন।
3. Hugging Face Space চালু/Running থাকতে হবে এবং তার API endpoint সক্রিয় থাকতে হবে।
4. Deploy শেষে অ্যাপ খুলে বাংলা অর্থের 🔊 বাটন চাপুন। প্রথমবার ইন্টারনেট লাগবে; পরে একই লেখা ক্যাশ থেকে চলবে।

গুরুত্বপূর্ণ: GitHub Pages-এ deploy করলে /api/speech function চলবে না; তখন ফোনের built-in বাংলা TTS fallback ব্যবহার হবে, আপনার cloned voice নয়। আপনার নিজের কণ্ঠে AI বাংলা ভয়েসের জন্য Cloudflare Pages (বা সমতুল্য serverless backend) ব্যবহার করুন।

আরবি কুরআনের পাঠ ও অনুবাদ অনলাইন API থেকে আনা হয়; প্রথমবার ইন্টারনেট লাগবে। নামাযের মাসআলা ও রাকাতের বিন্যাসে মতভেদ থাকতে পারে—স্থানীয় নির্ভরযোগ্য আলেমের নির্দেশনা অনুসরণ করুন।
